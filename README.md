# Compose Builder

Générateur de stacks Docker pour NAS auto-hébergé : choisis tes applications, il produit le `docker-compose.yml`, le `.env` et le script d'installation.

**Utiliser l'outil : [composebuilder.com](https://composebuilder.com)**

- Plus de 200 applications : médias (*arr, Jellyfin, Plex), clouds, sauvegarde, domotique, supervision, VPN et accès distant.
- Piles prêtes à l'emploi, secrets générés dans le navigateur, guide d'installation pas à pas.
- Interface en français et en anglais.

## Confidentialité

Tout tourne dans ton navigateur. Aucune donnée saisie n'est envoyée ni enregistrée : pas de compte, pas de serveur, pas de cookie. Seul le nombre de visites est compté, de façon anonyme, avec [GoatCounter](https://www.goatcounter.com).

## Utilisation hors ligne

Télécharge `index.html` et ouvre-le dans un navigateur : l'outil fonctionne tel quel.
